# Dove v2.1.1 顶部菜单优化 Spec

- 模式：AllInOne
- 分支：`feat/v2.1.1-top-menu`
- 基线：`master@d0922c3` / `2.1.0`
- 目标版本：`2.1.1`

## 目标与范围

- 顶栏固定为左侧“文件”、居中原翻页控件、右侧“设置”三个区域。
- “文件”展开纵向抽屉，依次提供“打开 PDF”和按 `openedAt` 倒序排列的最近 5 个文件名。
- 中间翻页按钮、页码与翻页逻辑不变。
- “设置”展开纵向抽屉，依次提供“安装”和“诊断”。
- 离线资源大小与进度在抽屉收起时显示于“设置”，展开时显示于“安装”；文字始终位于进度层上方并保持可读。
- PWA 已以 standalone 运行或收到 `appinstalled` 事件后，“安装”改为“已安装”。
- `feat/**` 分支 push 后自动执行基线测试、部署 Cloudflare Pages Preview 并运行设备模拟；BrowserStack 手动运行默认不启用。

## 非目标

- 不改变 PDF 渲染、翻页、OCR、查词、诊断面板或 Service Worker 缓存策略。
- 不新增最近文件的搜索、清理或排序选项。
- 本轮只做本地自动化和设备模拟验证，不把模拟结果表述为真机验收。

## 验收标准

- `AC-001`：顶栏只有三个布局区域，文件在左、原翻页控件居中、设置在右。
- `AC-002`：文件抽屉纵向显示“打开 PDF”和最多 5 个最近文件名，最近打开的在最前。
- `AC-003`：设置抽屉纵向显示“安装”“诊断”，诊断仍能打开原面板。
- `AC-004`：下载进度在设置/安装按钮间随抽屉状态迁移，不重复显示、不遮挡文字。
- `AC-005`：安装完成时按钮显示“已安装”。
- `AC-006`：键盘 Escape、点击抽屉外部及切换另一侧菜单均能关闭当前抽屉。
- `AC-007`：类型检查、目录校验、完整 PWA 离线回归和四端 Playwright 模拟通过。
- `AC-008`：GitHub Actions 摘要可回溯应用版本、分支、提交和 Cloudflare Preview URL。

## 关键决策

- 复用 `recentDocs()` 已有的日期倒序结果，在 UI 层截取 5 条。
- 复用 Service Worker 的 `done / total` 字节进度，用按钮内部的背景层表达百分比。
- 两个抽屉互斥，避免窄屏同时展开后相互遮挡。
- Cloudflare Pages 使用现有 `dove-e2e` 项目；功能分支 Preview 名由分支名派生，默认分支与定时任务仍保留真机门禁。
