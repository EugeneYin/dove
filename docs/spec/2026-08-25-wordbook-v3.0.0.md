# Dove v3.0.0 单词本 Spec

## 版本与范围

- 模式：AllInOne
- 分支：`feature/v3.0.0-wordbook`
- 基线：`stage@eecd07b` / `2.1.2`
- 目标版本：`3.0.0`
- 范围：新增本机单词本模块；不包含账号、云同步、导入导出或在线词典服务

## 用户故事

1. 用户可从顶栏“文件”右侧进入单词本，并返回 PDF 阅读页。
2. 用户可在三列表格中查看单词、音标、词性与含义。
3. 多行词性与含义在表格中合并为一行；列宽不足时可在单元格内横向滚动。
4. 用户可进入管理模式，以复选框选择并删除词条。
5. 用户可从页面底部“＋”添加单词；离线词典命中时自动补全，其余情况可手动填写。
6. 单词本保存在浏览器本地，离线冷启动后仍可恢复。

## 数据与限制

- 存储键：`localStorage["dove.wordbook.v1"]`。
- 自动补全复用现有 ECDICT 离线词典；没有网络请求。
- 词典未收录或加载失败时，音标和词性与含义保持可编辑。
- 数据只存在当前浏览器与当前站点来源中，清除站点数据会删除单词本。
