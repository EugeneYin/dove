# Dove v2.1.2 在线例句 Spec

- 模式：AllInOne
- 分支：`feature/v2.1.2-word-popup-examples`
- 基线：`master@31cf6c4` / `2.1.1`
- 目标版本：`2.1.2`

## 目标与范围

- 设置抽屉新增“在线例句”开关，默认关闭并在本地持久化选择。
- 开关关闭时保持原取词行为，不发起在线例句请求。
- 开关开启时在已收录词条的弹窗末尾增加“例句”折叠区，默认收起。
- 用户展开后从 FreeDictionaryAPI 获取并显示最多两条英文例句。
- 明确显示加载中、无例句和请求失败状态，并按数据源要求显示署名链接。

## 非目标

- 不修改现有离线词典内容和构建流程。
- 不生成或补写接口未提供的例句，不增加中文例句翻译。
- 不把在线例句加入 Service Worker 离线缓存。

## 验收标准

- `AC-001`：首次启动时在线例句开关关闭；用户选择可跨页面重载保存。
- `AC-002`：开关关闭时取词弹窗不出现例句区，也不请求在线接口。
- `AC-003`：开关开启后，取词弹窗末尾出现默认收起的例句区。
- `AC-004`：首次展开例句区才发起请求，并最多显示两条返回结果。
- `AC-005`：接口无例句或请求失败时显示明确状态，不伪造内容。
- `AC-006`：切换词条或关闭弹窗会取消尚未完成的旧请求。
- `AC-007`：单元测试、类型检查、PWA 回归和设备模拟通过。

## 关键决策

- 数据源使用无需密钥且支持 CORS 的 FreeDictionaryAPI v1，按响应中的词义顺序取例句。
- 请求延迟到用户展开折叠区时执行，避免浪费流量和触发接口每 IP 每小时 1,000 次的限制。
- 词形还原后使用原型词请求，例如 `conveys` 使用 `convey`。
